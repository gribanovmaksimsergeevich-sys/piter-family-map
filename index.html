Питер с Ромой: всё на карте

Выберите день или отдельную подборку: еда, места для взрослых, день рождения и рестораны с фиксированной ценой и городские пасхалки. Отмечайте галочкой, где уже побывали — выбор сохранится на этом телефоне.

© OpenStreetMap contributors · картографическая подложка без API ключа

Уличная подложка загружается при наличии интернета. Даже если сеть блокирует её, метки и список остаются доступны; для точной навигации нажмите «Маршрут» — откроются Яндекс Карты. Линии между точками обозначают порядок остановок.
