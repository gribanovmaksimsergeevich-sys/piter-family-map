# Питер с Ромой — семейная карта

Интерактивная светлая карта пятидневной поездки в Санкт-Петербург.

- Все места, пять дней, отдельный раздел еды и бюджетные альтернативы.
- Галочки посещения и адрес жилья сохраняются в браузере устройства.
- Уличная подложка OpenStreetMap загружается без API-ключа; ссылки навигации открываются в Яндекс Картах.

Для GitHub Pages опубликуйте содержимое корня репозитория из ветки `main`.

Дополнительно: вкладки «Для взрослых», «День рождения» и «Одна цена» показывают отдельные подборки с точками на карте, описаниями и ссылками на актуальные меню. Праздничные рестораны и заведения с фиксированной ценой также видны в разделе «Еда». Перед визитом проверьте часы работы, условия детской зоны и цены на сайте заведения.
